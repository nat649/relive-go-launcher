# Relive:GO (RL:GO) Launcher

Launcher officiel et auto-updater pour **Relive:GO** (CS:GO Legacy `AppID 4465480`).

## Fonctionnalités
- Détection automatique de votre dossier **CS:GO Legacy** via Steam (`libraryfolders.vdf`).
- Vérification automatique des mises à jour via `manifest.json` + contrôle d'intégrité **SHA-256**.
- Sauvegarde automatique du `csgo.exe` d'origine (`csgo.exe.bak`) avant la première installation.
- Statut en direct du serveur central Relive:GO (`https://rlgo.specs.qzz.io`) et actualités in-game.
- Zéro dépendance externe (fonctionne directement sur Windows 10 / 11).

## Installation pour les joueurs
1. Installez **CS:GO Legacy** depuis Steam (`AppID 4465480`).
2. Téléchargez **`ReliveGOLauncher.exe`** depuis la dernière [Release GitHub](https://github.com/nat649/relive-go-launcher/releases/latest).
3. Lancez **`ReliveGOLauncher.exe`** et cliquez sur **Mettre à jour & Jouer** !
